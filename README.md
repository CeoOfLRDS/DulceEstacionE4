# Dulce Estación - Ejercicio 4

Este es un programa de consola desarrollado en Java para administrar el inventario y alquiler de máquinas de golosinas[span_0](start_span)[span_0](end_span).

El sistema permite:
* Registrar máquinas de palomitas, de algodón de azúcar y fuentes de chocolate[span_1](start_span)[span_1](end_span).
* Calcular cotizaciones de alquiler según la categoría de la máquina y la cantidad de días solicitados[span_2](start_span)[span_2](end_span).
* Registrar el alquiler y la devolución de las máquinas, controlando su estado de disponibilidad[span_3](start_span)[span_3](end_span).
* Generar un reporte que muestra la cantidad de máquinas registradas, su estado (disponible o alquilada) y el total de ingresos acumulados[span_4](start_span)[span_4](end_span).
